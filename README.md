# Siseltronica Web

Sitio web de **Siseltronica** - Seguridad electrónica y automatización.

## Servicios

- **Cámaras de seguridad** - CCTV, IP, Dahua, Hikvision
- **Cerco eléctrico** - Instalación y configuración
- **Automatización** - Portones, controles de acceso
- **Cableado estructurado** - Redes y fibra óptica

## Tech Stack

- **Astro** - Framework web
- **Tailwind CSS** - Estilos
- **TypeScript** - Tipo seguro

## Commands

```bash
npm install
npm run dev      # Desarrollo local
npm run build    # Build de producción
npm run preview  # Previsualizar build
```

## Deploy

```bash
npm run build
```

El build se genera en `dist/`. Listo para desplegar en Netlify, Vercel, o cualquier hosting estático.
